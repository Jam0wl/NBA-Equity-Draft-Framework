
# Trades

## Pick-Trading im Equity Draft Framework (EDF)

Das Equity Draft Framework (EDF) erhält das bestehende Pick-Trading als
zentrales strategisches Element der NBA.

Teams können weiterhin Draft-Picks handeln, bündeln, schützen oder in
mehrjährigen Konstruktionen einsetzen.

------------------------------------------------------------------------

# 1. Grundprinzip: Was handelbar ist und was nicht

EDF trennt strikt zwischen zwei Komponenten:

1.  Base gehört zum Pick-Asset.
2.  Equity gehört zur Franchise-Leistung.

Base ist handelbar.
Equity ist nicht handelbar.

------------------------------------------------------------------------

# 2. Equity und Poolbindung

Equity entsteht ausschließlich durch Siege in den Final 29
und bleibt an die Franchise gebunden.

Zusätzlich gilt:

- Beendet eine Franchise die Saison im Lottery-Pool,
  kann sie Equity ausschließlich im Lottery-Bereich einsetzen.

- Beendet eine Franchise die Saison im Playoff-Pool,
  kann sie Equity ausschließlich im Playoff-Bereich einsetzen.

Eine Playoff-Franchise kann ihre Equity nicht zur Verstärkung
eines Lottery-Picks nutzen – selbst wenn sie durch Trades
Lottery-Picks besitzt.

Eine Lottery-Franchise kann ihre Equity nicht zur Verbesserung
eines Playoff-Picks einsetzen.

------------------------------------------------------------------------

# 3. Best-Pick-Regel bei mehreren First-Round-Picks

Equity wird pro Franchise exakt einmal angewendet.

Sie wird immer auf den base-stärksten verfügbaren First-Round-Pick
angewendet, der sich im selben Pool befindet, in dem die Franchise
die Saison beendet hat.

Kein Splitten.
Kein Stacking.
Keine poolübergreifende Anwendung.

------------------------------------------------------------------------

# 4. Systemlogische Bedeutung

EDF bewahrt die strategische Tiefe der NBA-Trade-Kultur,
verhindert jedoch, dass sportliche Leistung kaufbar wird
oder über Poolgrenzen hinweg strukturelle Vorteile erzeugt.
